Learn by tracing functions

  1. Swallowing: Identify the superior, middle and inferior pharyngeal constrictor groups and pharyngeal elevators. These muscles help organize pharyngeal movement; the source mesh depicts no contraction.
  2. Speech resonance: Find the levator veli palatini, tensor veli palatini and musculus uvulae. Velopharyngeal function contributes to oral–nasal resonance, but an open/closed port cannot be inferred from this static model.
  3. Airway landmarks: Select the tongue, epiglottis, hyoid and laryngeal cartilages to relate the pharynx to the separate larynx model. These viewers are not independently cross-registered.

Review prompt: Which three constrictor levels can you identify? Which of the displayed muscles helps elevate the soft palate? Then compare the notes and source mesh labels.
